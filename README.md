# 🔳 MONOSPACE

A minimalistic, low-distraction task organizer built to practice full-stack web development fundamentals in preparation for college. 

The project prioritizes utility and ultra-clean aesthetics, opting for a clean, minimal UI layout while diving deep into database integration and backend functionality.

## Tech Stack

* **Frontend:** HTML5, CSS, JavaScript 
* **Backend:** PHP
* **Database:** SQL

---

##  Key Lessons & Development Insights

* **Full-Stack Integration:** Connected a custom SQL database structure directly to a user-facing interactive frontend using PHP scripting.
* **Minimalist UI Styling:** Designed with a deliberate focus on a minimalist aesthetic, keeping user interactions straightforward and avoiding overly complex CSS positioning layouts.
* **JavaScript & Logic Flow:** Heavy emphasis on DOM manipulation and front-end event handling to keep task dynamic actions running smooth.
